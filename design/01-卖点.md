# superdev 项目卖点

superdev 是一套让 AI 团队自动交付软件的中台：AI 拆任务、写代码，程序管规则、管流程、管收工。一句话定位：**别人的工具管派活，superdev 管把活干成**——它是执行可靠性层，专治 AI 干活失败。前身 bigdev 已在生产运行多个项目，superdev 不推翻骨架，只对五个痛点做改造，每个改造对应一个明确机制。

## 六个核心卖点

### 卖点 1：规则由程序强制执行，AI 想违规也违不了

bigdev 的规矩写在提示词里，靠管理端 AI 自觉遵守，实际会跳步骤、越界代做。superdev 用 hook 拦截：越界写代码直接被挡，台账写错格式立刻被打回。规则从"大概率被遵守"变成"不可能被违反"。

### 卖点 2：改坏即退回，两次失败必须先查资料

bigdev 最痛的场景是工人在坏掉的代码上继续叠改动：上一轮改坏的不回滚，越改越远；同一思路重试五次零进展。superdev 给每个工人定死三条：从绿点开工；测试不过就整体退回；连续两次失败必须先研究再换方向，新方向要引用研究结论。省 token 的账在这里：烧钱的是失败回合，研究本身不烧。

### 卖点 3：流程不等定时器，事情一发生就推进

bigdev 靠 2/10/15/30 分钟四个定时器推进，每个动作平均多等半个周期；人拍板更要等几小时。superdev 把状态放进数据库，状态一变当场触发下一步（派工、恢复、合并检查），定时器降级为兜底对账。

### 卖点 4：失败升级更快，报告更有用

bigdev 要失败 5 次才上报专家，重试之间没有约束。superdev 两次失败就升级。报告带四样东西：失败用例、复现命令、每个已试方向及其证据、已花成本。误杀代价低（指标回升自动恢复），所以阈值敢砍到 2。

### 卖点 5：它开发自己也走这套流程

superdev 自己的代码改动由它自己的流水线交付，改自己的每一步也被自己的纪律和督办看管。"自己写的程序过不了自己的测试"这个死循环，恰好被自己的结构兜住。

### 卖点 6：四个执行引擎可换，私有网络可跑

工人引擎不绑死一家：ZCode、Codex、Kimi、Claude 用同一份契约。私有 git、飞书、本地部署，不假设 GitHub。飞书只发通知链接，真正的决策在自己网页上完成。

### 卖点 7：对手验证过的强项，全部吸收或兼容

竞品最强的能力都进了设计：spec-kit 的计划文件直接导入（它管写规范，我们管执行）；Bernstein 的合并前质检管线和防篡改审计链；Agent Orchestrator 的 CI 失败自动回喂；Vibe Kanban 的看板视图；Superpowers 的需求澄清和 AI 评审；troykelly 的跨任务记忆（一个仓灵过的改法，全项目复用）。争维度拉平、空位维度独占——"超越"是全维度事实，不是定位话术。

## 适合谁用

| 场景 | 例子 |
|---|---|
| 一个项目拆成多个仓库 | voc：七个仓一起管 |
| 一个仓库多会话并行 | 3d：`max_workers` 控制并行数 |
| 一个改造横跨多个项目 | docker 改造：待办 fanout 进各项目 |
| 回归测试密集、怕改坏的工程 | 红绿纪律的主场 |

## 为什么不直接拼现成项目

**→ 收敛纪律出自 Aider，抄规则不装本体。** Aider（~30k★ 的结对编程工具）的"每次改动自动跑测试、随时一键退回"正是我们要的纪律。但整个装进流水线会跟"工人独立负责提交"的分工打架，有用的部分 50 行脚本就能移植。

**→ 研究纪律出自 troykelly 技能集，同样只抄规则。** 两条规则直接写进契约：开工前按任务大小做研究；连败两次停止试错、先查资料。原技能把结论发到 GitHub issue，我们改成写台账。

**→ 规范先行的路线向 spec-kit 对齐，只借词汇。** spec-kit（GitHub 官方，~120k★）证明"先写规范、每个任务新开上下文"已是行业共识。superdev 的台账加每回合新分支是同一件事，模板词汇向它对齐，但不引入它的工具链。

**→ Bernstein 的哲学吸收，编排器本体不拼。** 它"调度不用 AI"的思路被 superdev 推到管理端行为层（hook 拦截）。但整套拼进来等于废掉自己的守护程序，变成双头指挥。

**→ Agent Orchestrator 同理。** 它的"CI 失败自动喂日志重试"有价值，但自带监督循环，拼进来冲突。

**→ Vibe Kanban 星最多（28.7k）但已日落。** Bloop 公司关停、转为社区维护，且假设 GitHub 生态，不能押。

一条原则总结：引擎级的硬骨头（编辑引擎、diff 容错）将来可以换件；纪律级的机制全部自己写进契约。superdev 需要的全是纪律级。
