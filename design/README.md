# superdev 设计文档

superdev 是一套让 AI 团队自动交付软件的系统：AI 负责拆任务和写代码，程序负责管规则、管流程、管收工。它脱胎于正在生产运行的前身 bigdev，针对 bigdev 暴露的五个问题做了改造。

它解决三个老问题：

1. AI 改代码总通不过回归测试 → 每次从"上次测试全过"的状态开工，改坏就整体退回，两次失败必须先查资料再换方向。
2. 流程靠定时器轮询，慢 → 事情一发生就自动推进下一步，不等下一轮。
3. 人拍板散在聊天记录里 → 网页上一键决定，立即生效。

## 术语表（首次阅读先看这个）

| 术语 | 意思 |
|---|---|
| 台账 | 记录任务、决策、状态的文件，git 管，全系统唯一事实 |
| 绿点 | 该模块全部测试通过的那个提交 |
| 红绿纪律 | 改坏即退回：测试红（不过）就回滚到绿点 |
| 事件驱动 | 发生即行动：状态一变就自动触发下一步 |
| 投影 | 数据库里的查询用副本，由程序从台账生成 |
| hook | 调用拦截器：AI 调工具前/后自动插入程序检查 |
| 督办 | 盯进度的程序：一段时间没进展就上报 |
| fanout | 把一份待办分发进多个项目的台账 |
| 管理端 | 出主意的 AI 会话：拆任务、判验收、定重派 |
| 工人（Worker） | 干活的 AI 会话：写码、测试、提交、开合并请求 |
